## 可重复运行

```powershell
# 包含构建、基础回归、GUI 工作流和隔离服务器检查
.\test\TortoiseSCM\Run-GuiExperienceTests.ps1

# 已对相同源码执行完整构建和回归时
.\test\TortoiseSCM\Run-GuiExperienceTests.ps1 -SkipBuild

# 单独复查重命名窗口正常/最小尺寸
.\bin\TortoiseSCM\Release\UiTests.exe --path-input-ui <截图目录>
```

统一入口按顺序运行，避免多个 GUI 测试的消息循环互相干扰。每阶段保存状态、用时、日志，GUI 子进程另外保存 stdout/stderr；失败中止并保留现场。真实写入均使用 `New-TestWorkspace.ps1` 生成的 `TestSCM` 专用 `tortoisescm-autotest-*` 分支和隔离 Standard/Gluon 工作区，不合并到 `/main`。

确认被测源码和二进制未变化时，可用 `-SkipBuild -Resume -Artifacts <原证据目录>` 跳过已经通过的阶段；原日志先备份到 `previous-run-*`，失败记录保留，按同名阶段最后一次记录判断最终结果。代码或配置改变后应使用新证据目录重新测试。

## 修复和剩余问题

**已修复 GUI-AUDIT-02：长源路径遮住重命名说明。** 原窗口将路径和操作说明放在同一固定高度标签内。现在源路径使用可选中复制的只读文本框，说明单独占行；默认/最小尺寸均能看到说明、目标路径框及确认/取消按钮。新增回归验证完整文本选择、说明所需高度、控件边界及取消不改变目标。

- [正常尺寸](images/gui-experience-20260929/rename-long-path.png)
- [最小尺寸](images/gui-experience-20260929/rename-long-path-minimum.png)

这验证长路径文本的显示，不代表已经验证 Windows 超长路径文件系统的所有操作。首次拉取、提交说明等集成测试的编译入口也补齐同一 Gluon ICO，避免测试窗口继续显示通用图标。

**已修复 Blame 刷新按钮高度。** 原 20 像素表格行压缩标准 26 像素按钮，现将该行增至 28 像素；正常/最小尺寸验证按钮高度、边界和实际刷新结果。[最终最小窗口](images/gui-experience-20260929/blame-live-minimum.png)。

**已修正首次拉取测试的初始化和截图。** 原测试注入已加载状态，标题仍显示“正在识别工作区”，且将完整窗口绘制到客户区导致截图底部裁切。现调用真实初始化、核对配置客户端和范围文本，并按完整窗口尺寸渲染，检查提交按钮正常/最小尺寸可见；真实流程最终 26 项通过。[最终最小窗口](images/gui-experience-20260929/first-checkout-main-minimum.png)。这是测试证据修正，未将它记为产品修复。

**仍需处理 GUI-AUDIT-03：签出/撤销 Shell 入口引导。** 当前进入待定更改窗口后，主按钮仍是提交，用户要从操作菜单继续选择签出/撤销；操作能够执行与首次使用体验顺畅是两件事。本轮保留该待办，没有用处理器测试通过来关闭它。

**新记录 GUI-EXPERIENCE-01（P2）：深路径下主窗口范围信息裁切。** 首次拉取最终截图中，38 像素固定标题行被换行后的工作区路径占满，“范围”行不可见；正常/最小窗口均可复现。底部提交按钮可见不等于顶部所有信息完整显示，后续应分离工作区路径与操作范围。

**桌面版本仍落后。** 当前用户安装记录仍为 `0.1.0-dev-shell-dispatch-fix-20260928`。源码构建的新图标、菜单顺序和布局修正不能推断已出现在用户 Explorer 中。待桌面控制服务恢复并部署与测试一致的版本后，需要补测右键启动、覆盖图标、退出、Explorer 重载、原生文件对话框和 BC 三方编辑。

深色/高对比度、其他系统语言、真实大仓库性能和长时间网络故障结果核对仍保持未验收。ROADMAP 尚未实现的 changelist、补丁、批量移动/删除/忽略、拖放、首次稀疏加载等也不计为测试通过。用户已排除的多 DPI 等工作未重新列为完成条件。
